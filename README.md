# Zixflow iOS SDK - SPM Distribution

This repository contains the pre-built XCFramework for the Zixflow iOS SDK, distributed via Swift Package Manager.

## Installation

### Swift Package Manager

Add the following to your `Package.swift` file:

```swift
dependencies: [
    .package(url: "https://github.com/zixflow/zixflow-ios-spm.git", from: "1.0.0")
]
```

Or add it directly in Xcode:
1. Go to File > Add Package Dependencies
2. Enter the repository URL: `https://github.com/zixflow/zixflow-ios-spm.git`
3. Select the version: `1.0.0`
